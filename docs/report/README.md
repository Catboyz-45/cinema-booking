# รายงานวิชาการวิเคราะห์และออกแบบระบบสารสนเทศ (02739322)

รายงานเรื่อง **ระบบซื้อตั๋วภาพยนตร์ออนไลน์** ฉบับปรับปรุงตามระบบที่พัฒนาจริง

| ไฟล์ | รายละเอียด |
| --- | --- |
| `35-ณัฐภัทร-ระบบซื้อตั๋วภาพยนตร์ออนไลน์.pdf` | รายงานฉบับสมบูรณ์ |
| `35-ณัฐภัทร-ระบบซื้อตั๋วภาพยนตร์ออนไลน์.docx` | ต้นฉบับ Word แก้ไขได้ (ฟอนต์ TH SarabunPSK) |
| `diagrams/*.drawio` | ต้นฉบับแผนภาพ เปิดแก้ด้วย [draw.io](https://www.drawio.com) |
| `diagrams/*.png` | แผนภาพที่ส่งออกแล้ว ใช้ในรายงาน |

แผนภาพในรายงาน: สถาปัตยกรรมระบบ, HTA, Context Diagram, DFD ระดับ 1, ER-Diagram (Chen) และความสัมพันธ์รายคู่ (rel1–rel9), Decision Tree, Use Case, Class, Activity และ Sequence Diagram

ส่งออกแผนภาพใหม่หลังแก้ไข:

```bash
drawio -x -f png -s 2 -b 10 -o diagrams/er.png diagrams/er.drawio
```
